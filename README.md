# استوديو الأغلفة — تطبيق أندرويد

تطبيق أندرويد يحتوي استوديو الأغلفة السينمائي كاملاً بكل ميزاته: القوالب، والمعالج السريع، والنصوص والتأثيرات، وإزالة الخلفية مع محرر القص، والمكتبة، والخلفيات المولّدة، والمؤثرات، والتدرّج اللوني، والعناصر، والحفظ والتصدير.

تطوير أبو عبدالله الشامي

## بناء ملف APK تلقائياً عبر GitHub

1. المستودع: `CoverStudio`. **يجب أن يكون عاماً (Public)** حتى يعمل التحديث الصامت (التطبيق يقرأ التحديثات من المستودع دون تسجيل دخول).
   - للأمان: أضف سرّاً باسم `KEYSTORE_PASSWORD` من Settings ← Secrets and variables ← Actions ← New repository secret، وضع فيه كلمة سر مفتاح التوقيع.
2. ارفع **محتويات هذا المجلد** إلى المستودع (Add file ← Upload files). تأكد من رفع المجلد المخفي `.github` أيضاً.
3. افتح تبويب **Actions** وانتظر انتهاء البناء (5–8 دقائق).
4. ستجد ملف APK في:
   - تبويب **Releases** في صفحة المستودع: رابط تنزيل مباشر يُفتح من الهاتف.
   - أو داخل البناء نفسه في Actions ← Artifacts.

## كيف يعمل البناء

- كود الاستوديو في `web/src/app.jsx`.
- أثناء البناء على GitHub تُنزَّل React وKonva والخطوط العربية السبعة ومكتبة إزالة الخلفية، وتُدمج داخل التطبيق في `app/src/main/assets`.
- لذلك لا يعتمد التطبيق على مواقع CDN، ويفتح حتى دون إنترنت. الإنترنت مطلوب فقط لتوليد الخلفيات، والبحث في مكتبة العناصر، وتنزيل نموذج إزالة الخلفية في أول استخدام.

## التحديث الصامت داخل التطبيق

- كل بناء على GitHub ينشر ملفات الواجهة في فرع `web-update` داخل المستودع.
- التطبيق يفحص هذا الفرع بصمت عند كل فتح، ويُنزّل الملفات المتغيّرة فقط، ويُطبّقها في الفتح التالي دون أي رسالة.
- إن فشل الإصدار الجديد في التشغيل يعود التطبيق تلقائياً للإصدار السابق.
- تعديلات الواجهة (القوالب، الخطوط، المؤثرات، الأدوات…) تصل للمستخدمين **دون تثبيت APK جديد**. أما تعديلات كود أندرويد نفسه (Java) فتحتاج APK جديداً.

## تحديث التطبيق لاحقاً

- استبدل الملفات التي أرسلها لك المطوّر (غالباً `web/src/app.jsx`).
- ارفع `versionCode` بمقدار 1 في `app/build.gradle.kts` حتى يقبل الهاتف التحديث.
- ارفع التغييرات، فيُبنى APK جديد يُثبَّت فوق القديم دون فقدان البيانات (التوقيع ثابت).

## ملاحظات

- **الحفظ:** صور الأغلفة تُحفظ في `الصور/استوديو الأغلفة`، وملفات المشاريع في `التنزيلات/استوديو الأغلفة`.
- **مفتاح التوقيع:** الملف `app/release.keystore` بكلمة المرور `coverstudio2026`. احتفظ بنسخة منه، فهو ضروري لنشر التحديثات وتثبيتها فوق النسخة السابقة.
- يعمل على أندرويد 8.0 فما فوق.
- **محرك إزالة الخلفية مدمج داخل التطبيق** (نموذج «متوازن» + محرك التشغيل)، لذلك حجم APK كبير (حوالي 100–130MB). خيارا «دقة قصوى» و«سريع» يُنزَّلان من الإنترنت عند أول استخدام.
